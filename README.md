# 🌐 Developer Portfolio Landing Page

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-2ea44f?style=flat&logo=github)](https://tawsifx.github.io/phero-portfolio-demo/)

A clean, responsive personal portfolio landing page built as an early web development project during Programming Hero training. It showcases core HTML5 semantics, custom CSS styling, flex layouts, and typography.

---

## 🔗 Live Preview

Check out the live deployment on GitHub Pages:  
👉 **[View Live Site](https://tawsifx.github.io/phero-portfolio-demo/)**

---

## ✨ Features

- **Hero & Intro Banner**: Engaging header section with profile introduction and call-to-action buttons.
- **Biography & Experience**: Structured about-me section highlighting background, skills, and resume download.
- **Latest Works Showcase**: Responsive grid displaying featured work samples.
- **Client Testimonial Section**: Customer feedback quote with clean card typography.
- **Contact & Footer**: Contact email channel, copyright notice, and social media connectivity.

---

## 🛠️ Built With

- **HTML5**: Semantic document structure
- **CSS3**: Custom layouts, responsive styling, and gradients
- **Google Fonts**: [Poppins](https://fonts.google.com/specimen/Poppins)
- **GitHub Pages**: Automated static site hosting

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tawsifx/phero-portfolio-demo.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd phero-portfolio-demo
   ```

3. **Open `index.html`** in any web browser, or launch it with a live server (e.g., VS Code Live Server extension, `python3 -m http.server 8000`, or `npx serve`).
